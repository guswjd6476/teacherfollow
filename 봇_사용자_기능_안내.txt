==================================================
  상담/복음방 일정 관리 봇 - 사용자 기능 안내
  (관리자 전용 기능 제외)
==================================================

※ 명령어는 / 또는 ! 로 시작합니다. (예: /상태확인, !상태확인)
※ 상담방(그룹)에서 사용하는 명령어는 해당 방 기준으로 동작합니다.


--------------------------------------------------
0. 처음 시작하기 (사용 인증)
--------------------------------------------------
- 봇은 인증된 사용자만 사용할 수 있습니다. 인증은 처음 한 번만 하면 됩니다.
  1) 봇과 개인 대화를 열고 /start 입력
  2) [🔐 인증 요청하기] 버튼 누르기
  3) 관리자가 승인하면 "인증이 승인되었습니다" 메시지가 옵니다.
- 인증된 사람이 상담방에 봇을 초대해야 그 방에서 봇이 동작합니다.
  (인증되지 않은 사람이 초대하면 봇이 안내 후 자동으로 나갑니다)
- 도움말: /도움말 (또는 /help)


--------------------------------------------------
1. 상담방 등록
--------------------------------------------------
- 대상자 최초 등록
    /최초등록 섭외자/지역/팀/인도자
    예) /최초등록 홍길동/강북/1/강현정
  → 대상자가 매칭되면 첫 만남 유형을 버튼으로 선택합니다.
    [🎙️ 인터뷰 만남] [👨‍🏫 교사 만남] [🎉 지역행사] [🧩 동아리] [🤝 지인 만남]
  → 유형을 잘못 골랐다면 /유형변경 (또는 유형 버튼을 다시 누르기)
    · 인터뷰 결과 보고서 전, 교사 만남 회차가 쌓이기 전까지 바꿀 수 있습니다.
    · 인터뷰에서 바꾸면 사전 보고서 내용(인터뷰어·타이퍼·인터뷰일)은 지워지고, 만남일은 그대로 둡니다.
  → 봇을 실수로 내보냈다가 다시 초대하면 이전 기록(대상자·회차 등)이 복원됩니다.

- 현재 방 상태 확인 : /상태확인
  (대상자, 만남 유형, 다음 만남일, 피드백/보고서 제출 여부, 교사 만남 누적 회차 등)
- 행정 등록 확인    : /행정확인
  (현재 단계와 단계별 등록일)
- 목표월 수정       : /목표월수정 n월    예) /목표월수정 11월
- 매칭 초기화       : /매칭해제
  (대상자 매칭과 인터뷰 설정을 모두 초기화)


--------------------------------------------------
2. 인터뷰 만남
--------------------------------------------------
- 대상자 연락 확인 : 인터뷰로 지정하고 다음 날까지 사전 보고서가 없으면 오전에 안내가 옵니다.
    [✅ 연락 확인됨] → 사전 보고서 양식이 바로 나옵니다.
    [⏳ 연락 대기중] → 오전 안내 때 다시 확인합니다.
    [📵 연락 안 됨] → 지역 담당방에 알리고, 오전 안내 때 다시 확인합니다.
    (버튼을 누를 때마다 안내 횟수를 새로 셉니다. 최대 3번 안내 후 담당방 요약)
- 사전 보고서 양식 : /인터뷰사전양식
- 사전 보고서 제출 : 방에 [인터뷰 사전 보고서] 양식을 작성해 전송
  → 인터뷰어 / 타이퍼 / 인터뷰 일시가 자동 등록됩니다.

- 항목 개별 수정
    인터뷰어 : /인터뷰어 강북 1팀 홍길동
    타이퍼   : /타이퍼 강북 1팀 김철수   (해제: /타이퍼 없음)
    예정일   : /인터뷰일 MM-DD

- 결과 보고서 양식 : /인터뷰사후양식
- 결과 보고서 제출 : 방에 [인터뷰 결과 보고서] 양식을 작성해 전송
    · 후속신청: 신청   → 교사 만남으로 자동 전환, 다음만남일 등록
    · 후속신청: 미신청 → 만남 중단 처리, 미신청 사유를 버튼으로 선택
    · 후속신청: 행사참석 → 상담이 아닌 [행사 참석]으로 따로 기록 (다음만남일 또는 '행사일:'을 행사일로 등록)
      행사 참석은 일정만 관리하고, 행사 후 상담으로 이어지면 /교사전환
- 인터뷰 전에 연락두절·거절된 경우 : /만남중단 → 사유 선택
    · 인터뷰 결과 보고서 전에 중단하면 [인터뷰 전 중단]으로 구분되어 기록됩니다.


--------------------------------------------------
3. 교사 만남
--------------------------------------------------
- 만남일 등록      : /만남일 MM-DD   또는   /만남일 미정
                     시간도 함께 적으면 저장됩니다. 예) /만남일 10.8(목) 오후 7시
- 사전 피드백 제출 : 메시지에 #피드백 태그를 포함해 작성
- 만남 보고서 양식 : /만남보고서양식 (또는 /교사만남양식)
- 만남 보고서 제출 : 양식에 "다음만남일: MM-DD"를 포함해 전송
    · 진행내용, 상담반응 및 특이사항은 필수 항목입니다.
      (비어 있으면 제출로 처리되지 않습니다)
    · 다음만남일이 자동으로 갱신됩니다. (미정이면 "다음만남일: 미정")
    · 사진 설명글로 올려도 인식됩니다.
    · 이미 보낸 메시지를 편집(수정)하면 반영되지 않습니다. 고친 보고서는 다시 올려 주세요.

[교사 만남 누적 회차]
- 만남 보고서가 반영될 때마다 자동으로 1회씩 누적됩니다.
    · 같은 만남일로는 1회만 셉니다.
    · 다음 만남일이 오기 전에 다시 올린 보고서는 "수정본"으로 처리되어
      회차가 늘지 않습니다. (다음 만남일은 수정본 기준으로 갱신)
    · 인터뷰 만남, 지역행사·동아리·지인 만남은 세지 않습니다.
- 회차 확인 : /교사만남회차   (회차별 만남 날짜 목록)
- 회차 보정 : /교사만남회차 총횟수   예) /교사만남회차 5
              (봇 도입 전에 만난 횟수를 포함해 맞출 때)
- 잘못 누적된 회차 취소 : /회차취소   (마지막 1회 삭제)

[섭등 후 회차]
- 섭등한 날의 만남을 1회차로 보고, 이후 교사 만남마다 +1 됩니다.
  (섭등일은 행정의 섭 등록일 기준)
- 확인 : /섭등회차
- 보정 : /섭등회차 총횟수   예) /섭등회차 3
- 복등 안내 : 섭등 후 3회차부터 아직 복등 전이면, 만남 보고서가 반영될 때 복등 안내가 옵니다.


--------------------------------------------------
4. 지역행사 · 동아리 · 지인 만남 (일정만 관리)
--------------------------------------------------
- /최초등록 후 [🎉 지역행사] · [🧩 동아리] · [🤝 지인 만남] 중 선택
- 일정 등록 : /만남일 MM-DD   또는   /만남일 미정
- 보고서 제출 안내, 미제출 경고는 보내지 않습니다. (하루 전 일정 안내만 발송)
- 교사 만남으로 넘어가면 : /교사전환
  → 교사 만남으로 바뀌고, 이후 교사 만남 주기에 맞춰 관리됩니다.


--------------------------------------------------
5. 만남 중단
--------------------------------------------------
- /만남중단 [상세 사유]   예) /만남중단 연락 두절 2주째
  → 사유 분류 버튼을 누르면 중단 처리됩니다.
  → 행정(학생 관리)에도 탈락 처리해 주세요. 안 되어 있으면 마감 요약에 나옵니다.
- 만남이 재개되면 /만남일 MM-DD 로 새 일정을 등록하세요.


--------------------------------------------------
6. 방 진행 단계 (특수 구분)
--------------------------------------------------
- 단계 설정 (날짜만 입력)
    /섭등목표 MM-DD
    /예정목표 MM-DD
    /가능목표 MM-DD
    /확정목표 MM-DD
- 단계 해제 : /구분해제   (일반 상태로 복귀)
- 설정한 날짜 당일 오전에 방으로 안내 메시지가 갑니다.


--------------------------------------------------
7. 날짜 입력 형식
--------------------------------------------------
- 10-08, 10/8, 10.8(목), 10월 8일, 2026.10.8, 내일
- 시간 함께 입력 : 10/8 19:30, 10.8(목) 오후 7시
- 요일이 실제와 다르거나 지난 날짜면 안내해 드립니다.


--------------------------------------------------
8. 상담방 자동 알림
--------------------------------------------------
[오전 10시]
- D-1 안내      : 내일 만남 예정 안내
                  (교사 만남: #피드백 작성 요청 / 인터뷰: 인터뷰어·타이퍼 안내
                   / 지역행사·동아리·지인: 일정 안내만)
                  인터뷰는 [✅ 연락 확인됨] [⏳ 연락 대기중] [📵 연락 안 됨] 버튼으로 대상자 연락을 확인합니다.
                  '연락 안 됨'을 누르면 지역 담당방에 바로 알립니다.
- D+1 미제출    : 어제 만남의 보고서가 없으면 안내
- D+2 지연 경고 : 만남일로부터 2일이 지나도 보고서가 없으면 경고
- 진행 단계 당일 안내 : 섭등목표 등 설정한 날짜 당일

[밤 10시]
- 오늘 만남의 보고서가 아직 없으면 제출 안내

※ 지역행사·동아리·지인 만남은 보고서 관련 알림(D+1, D+2, 밤 10시)을 받지 않습니다.


--------------------------------------------------
9. 지역 담당방에서 받는 알림 (참고)
--------------------------------------------------
관리자가 지역 담당방으로 등록한 방에는, 그 지역 인도자·교사의 상담방에 대해
아래 알림이 자동으로 옵니다.
- 🚨 보고서 제출 지연 (만남일 2일 경과)
- 🛑 만남 중단 발생
- 📵 인터뷰 전날 대상자 연락 안 됨
- ☀️ 오전 10시 지역 요약 : 오늘 만남(인터뷰는 연락 확인 여부), 보고서 미제출
- 🌙 밤 10시 마감 요약   : (맨 위) 이번 주 행정 결과 / 주간 목표
                             · 오늘 등록한 단계별 점수
                             · 월요일부터 요일별 누적 / 주간 목표 (오늘은 달성률 %)
                             · 팀별 누적 / 주간 목표
                           오늘 신규 만남 발생, 오늘 보고서 미제출,
                           이전 미제출, 행정 탈락 처리 확인(봇 중단·행정 진행 중), 내일 만남
- 📅 월요일 오전 10시 지난주 결산 : 지난주 행정 결과 / 주간 목표(팀별),
                           신규 만남(인터뷰 후 교사 전환), 중단 건수·사유, 지금 확인할 것
- 📢 관리자 공지


--------------------------------------------------
진행이 멈춘 방 안내 (오전 10시, 자동)
--------------------------------------------------
- 아래 상황이면 해당 방으로 안내가 갑니다.
  · 봇을 초대했는데 /최초등록을 하지 않음
  · 최초등록 후 첫 만남 유형(인터뷰/교사/지역행사/동아리/지인)을 고르지 않음
  · 인터뷰 만남인데 사전 보고서가 없음 / 인터뷰 예정일이 미정
  · 인터뷰일이 3일 넘게 지났는데 결과 보고서가 없음
  · 교사·지역행사·동아리·지인인데 만남일이 없음
  · 지난 만남 이후 다음 만남일이 등록되지 않음
  · 만남 보고서가 3일 넘게 제출되지 않음
  · 만남일이 '미정'으로 14일 넘게 지남
  · 교사 만남이 2회 넘게 진행됐는데 행정이 아직 발·찾이거나 교사 미지정 → 행정 등록 안내
  · 행정 합 14일 / 섭·복 21일 넘게 다음 단계 전 → 단계 진행 확인 안내
    (/섭등목표·/예정목표로 앞으로의 목표일을 등록해 두면 안내하지 않습니다)
  · 행정에서 탈락 처리된 대상자 → [중단 사유] 또는 [계속 진행] 버튼으로 확인
    (확인 전까지 그 방의 일정·보고서 알림은 멈춥니다)
- 방마다 하루에 하나, 상황별 최대 3번까지 안내합니다.
  3번 안내 후에도 그대로면 지역 담당방에 요약으로 알립니다.
